# Contributing

- Open an issue before a pull request that changes the meaning of a member.
- Prose changes go to `spec/` and `draft/` together; they are the same text
  in two forms.
- Schema changes need an example that exercises them.
- A change that alters what a value means is a new `version`. Adding an
  optional member is not.
- By contributing prose you license it under CC BY 4.0; schemas, examples
  and code under Apache-2.0. Contributions to `draft/` are subject to the
  IETF Trust's provisions (BCP 78 and 79) once the draft is submitted.
- Be concrete. Every statement about another specification names the
  document and revision it was checked against.
